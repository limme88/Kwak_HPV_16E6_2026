# ELViM landscape

Revision V12 Figure 4a–d and the associated basin analysis require the original
E6 ELViM projection, basin-extraction and order-parameter visualization scripts.
The final E6 scripts and saved projection have not yet been recovered. No runnable command
or run order can be supplied faithfully without these files. Unrelated NUPR1
ELViM implementations have deliberately not been substituted.

The V12 manuscript identifies the external implementation as
[ELViM](https://github.com/VLeiteGroup/ELViM). Its exact version/commit is not
specified in that manuscript and was not recovered. Install that external tool
separately once the original version is established; its third-party source is
not redistributed here. The manuscript reports sigma0=1.0 Å, epsilon=0.15,
force-scheme learning rate 0.4 to 0.05, and SciPy Gaussian KDE. Those descriptions
alone are insufficient to reconstruct the original code or projection.
